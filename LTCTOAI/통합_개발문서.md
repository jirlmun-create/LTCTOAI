# AI 기반 장기요양 평가 보고서 생성기: 통합 개발 문서 (확장성 강화 버전)

## 프로젝트 개요 및 목표
- **프로젝트명:** AI 기반 장기요양 평가 보고서 생성기
- **목표:** PDF, 엑셀, 워드, 한글(HWP) 등 다양한 문서 자료를 AI로 분석하여, 어르신별 기록을 평가 기준에 맞게 자동 보고서로 생성하는 GUI 애플리케이션 개발
- **확장성:** 신규 문서 형식 추가 시 해당 모듈만 구현하면 전체 파이프라인 자동 연동

## 주요 기능 및 기술 스택
- PC용 GUI 애플리케이션(사무실 네트워크 공유 지원)
- Hugging Face 모델 파인튜닝
- 멀티프로세스/멀티스레드 대용량 분석
- 교차점검 및 자동 보고서 생성
- 대화형 프롬프트 기능(질문/답변)
- Python, PyQt5, pandas, matplotlib, fpdf, python-docx, pyhwp 등
- 다양한 문서 자동 탐색/분석: PDF, 엑셀(xls/xlsx/csv), 워드(doc/docx), 한글(HWP)

## 문서 자동 처리 구조
- document_loader.py에서 load_document(path) 함수로 통합
- 파일 확장자별로 처리 모듈 분리: pdf_loader.py, excel_loader.py, word_loader.py, hwp_loader.py 등
- UI에서 파일 선택 시 자동으로 형식 감지 및 적절한 모듈 호출
- 데이터 분석, 파인튜닝, 보고서 생성 등 모든 기능에서 다양한 문서 형식 지원

## document_loader.py 예시
```python
import os
import pandas as pd
from typing import Union

def load_document(path: str) -> Union[str, pd.DataFrame, dict]:
    ext = os.path.splitext(path)[-1].lower()
    if ext == '.pdf':
        from pdfminer.high_level import extract_text
        return extract_text(path)
    elif ext in ['.xls', '.xlsx']:
        return pd.read_excel(path)
    elif ext == '.csv':
        return pd.read_csv(path)
    elif ext in ['.doc', '.docx']:
        from docx import Document
        doc = Document(path)
        return '\n'.join([p.text for p in doc.paragraphs])
    elif ext == '.hwp':
        try:
            import olefile
            return "(HWP 텍스트 추출 예시)"
        except ImportError:
            return "pyhwp/olefile 미설치"
    else:
        return "지원하지 않는 파일 형식입니다."
```

# KoAlpaca 파인튜닝/추론 실무 적용 가이드

## 1. 데이터셋 변환
- 분석 결과(CSV/JSON/TXT)를 KoAlpaca 파인튜닝용 JSONL로 변환
- 예시 코드: `convert_to_koalpaca.py`

## 2. 파인튜닝 파이프라인
- KoAlpaca 모델(예: beomi/KoAlpaca-Polyglot-12.8B) 기반 파인튜닝
- 예시 코드: `finetune_koalpaca.py`
- 필요 라이브러리: `transformers`, `datasets` (pip 설치)

## 3. 추론(테스트) 파이프라인
- 파인튜닝된 모델로 질문/답변 테스트
- 예시 코드: `infer_koalpaca.py`

## 4. 실무 적용 절차
1. 분석 결과를 `datasets/` 폴더에 저장
2. `convert_to_koalpaca.py`로 JSONL 변환
3. `finetune_koalpaca.py`로 파인튜닝 수행
4. `infer_koalpaca.py`로 결과 테스트 및 실무 적용

## 5. 참고
- 파인튜닝/추론 예시 코드는 실무 환경에 맞게 경로/파라미터 수정 가능
- 대용량 데이터/모델은 GPU 환경 권장
- 데이터셋 구조와 파이프라인만 맞추면 다양한 한국어 LLM(예: KoGPT)에도 동일 적용 가능
